# Техническая документация проекта: Завод промышленных цепей (статический сайт)

## 1. Общее описание
- **Тип проекта**: статический сайт (без backend, CMS) для завода по производству промышленных цепей.
- **Цель**: демонстрация продукции, услуг, контактов; сбор заявок через формы.
- **Основные страницы**:
  - `/` — главная (одностраничный сайт с якорными секциями)
  - `/catalog/` — каталог продукции (генерируется из JSON на клиенте)
  - `/privacy-policy/` — политика конфиденциальности (статический текст)
- **Языки**: русский (основной) и английский (переключение без перезагрузки через JS).
- **Формы**: отправка через внешние сервисы (EmailJS, Formspree и т.п.), без собственного backend.
- **Хостинг**: любой статический хостинг (Netlify, GitHub Pages и т.п.).

## 2. Технологический стек
- **Frontend**: HTML5, SCSS (компилируется в CSS), чистый JavaScript (ES6+), без тяжёлых фреймворков. Для слайдера допустимо использовать лёгкую библиотеку (Slick Slider). Для модальных окон — чистый JS или Micromodal.js.
- **Данные**: статические JSON-файлы (каталог, переводы).
- **Сборка**: не обязательна; допускается ручная компиляция SCSS в CSS. Для простоты можно использовать Gulp/Webpack, но не обязательно.
- **Зависимости**: минимальные (Slick Slider, возможно Micromodal). Всё подключается через CDN.

## 3. Структура главной страницы
- **Хедер**:
  - Логотип (слева), телефон с кнопкой «Заказать звонок», e-mail.
  - Меню: «Каталог» (ведёт на `/catalog/`), «О заводе» (якорь `#about`), «Клиентам» (якорь `#clients`), «Контакты» (якорь `#contacts`).
  - Переключатель языка (RU/EN) справа.
  - Мобильная версия: гамбургер-меню.
- **Герой-блок (Hero)**:
  - Полноэкранный Slick-слайдер с фото производства. Поверх каждого слайда — изменяемый текст о предприятии.
  - Внизу слайдера — горизонтальная широкая картинка цепи, двигающаяся горизонтально при перелистывании слайдов.
  - Заголовок H1: «Производство промышленных цепей полного цикла».
  - Подзаголовок: «От проектирования до поставки по всей России».
  - Две CTA-кнопки: «Перейти в каталог», «Связаться с нами».
- **Секция «Продукция»** (`#products`):
  - Карточки категорий: Приводные цепи, Тяговые пластинчатые цепи, Транспортные цепи, Грузовые цепи, Вильчатые цепи, Цепи под заказ.
  - Клик по карточке ведёт на `/catalog/` с открытием соответствующего модального окна (опционально).
- **Секция «О заводе»** (`#about`):
  - Три подраздела (без аккордеонов, просто последовательные блоки):
    1. История и миссия
    2. Производство и технологии (собственное КБ, лаборатория, контроль качества, индивидуальные заказы)
    3. Сертификаты и качество
  - Блок с цифрами/фактами: «Доставка в любой регион РФ».
- **Секция «Клиентам»** (`#clients`):
  - Пять подразделов (последовательно):
    1. Как заказать (пошаговая инструкция)
    2. Оплата и доставка
    3. Гарантия (до 24 месяцев)
    4. Контакты (`#contacts`): телефон, e-mail, форма обратной связи (ФИО, телефон, e-mail, сообщение), кнопка «Оставить заявку» (открывает общую pop-up форму), реквизиты.
    5. Вопрос-ответ (FAQ)
- **Футер**:
  - Копирайт, контакты, ссылки на соцсети, быстрые ссылки на разделы, ссылка на `/privacy-policy/`.

## 4. Страница каталога `/catalog/`
- Содержит сетку карточек категорий (6–8 шт.) с иконкой, названием, кратким описанием.
- При клике на карточку открывается модальное окно (или раскрывающийся блок) со списком товаров категории.
- В модальном окне:
  - Заголовок категории.
  - Карточки товаров: фото (опционально), название, характеристики (шаг, нагрузка), кнопка «Запросить цену».
  - Кнопка «Запросить цену» открывает общую pop-up форму заявки.
  - Закрытие: крестик или клик вне окна.
- **Данные каталога** хранятся в `catalog.json` следующей структуры:
```json
{
  "categories": [
    {
      "id": 1,
      "name": "Приводные цепи",
      "icon": "path/to/icon.svg",
      "description": "Краткое описание",
      "products": [
        { "name": "Цепь ПР-19,05", "step": "19,05 мм", "load": "22 кН" }
      ]
    }
  ]
}
```
- **Фильтрация/поиск**: опционально, простой поиск по названию товара внутри модального окна.

## 5. Единая pop-up форма заявки
- Вызывается:
  - sticky-кнопкой «Оставить заявку» (левый нижний угол, на всех страницах);
  - кнопкой «Запросить цену» в каталоге;
  - кнопкой «Оставить заявку» в блоке «Контакты» на главной.
- Поля:
  - ФИО (обязательное)
  - Телефон (обязательное, маска +7 (___) ___-__-__)
  - E-mail (обязательное, валидация)
  - Сообщение / ТЗ (многострочное, необязательное)
  - Прикрепление файлов (до 5 файлов, допустимые типы: .pdf, .jpg, .png, .dwg, .doc, .docx, .xls, .xlsx, макс. 10 МБ каждый)
  - Кнопка «Отправить».
- После отправки: показ сообщения об успехе, очистка формы.
- Отправка: через внешний сервис (Formspree, EmailJS и т.п.). В демо-версии можно использовать `mailto:` или заглушку с имитацией успеха.
- Валидация: HTML5 + JS. Защита от спама: простая скрытая ловушка или reCAPTCHA v3 (опционально).

## 6. Анимационные требования
- **Следящая цепь из 6 звеньев** (только десктоп ≥ 768px):
  - Расположена в верхнем левом углу (левее логотипа), свисает вертикально.
  - Следует за курсором с коэффициентом 1:1 (без задержки) через `requestAnimationFrame`.
  - Фиксирована относительно окна браузера (`position: fixed`), `z-index: 9999`.
  - Отключается на мобильных (< 768px).
  - Звенья: первое прикреплено к курсору, остальные следуют за первым (с минимальной инерцией или без).
- **Боковые декоративные цепи** в каждой секции:
  - Абсолютное позиционирование внутри секций (`position: absolute`).
  - Двигаются вместе с секцией при скролле (не фиксированы).
  - На мобильных — уменьшенный размер, но остаются.
  - Ширина цепей: `max-width: 15%` от ширины блока.
  - Использовать `transform` и `opacity` для анимаций.

## 7. Мультиязычность (RU/EN)
- Переключение кнопкой в хедере.
- Все текстовые элементы имеют атрибут `data-i18n="ключ"`.
- Переводы хранятся в двух JSON-объектах `translations.ru` и `translations.en` (могут быть в отдельном файле `translations.js`).
- При переключении JS заменяет `textContent` (или `innerHTML` для элементов с разметкой) согласно ключам.
- URL не меняется.
- Изображения не содержат текста — одинаковые для обоих языков.
- Мета-теги остаются на русском (или переключаются опционально).

- **Главная страница**:
  - Title: «Завод промышленных цепей – производство цепей полного цикла в России | Название компании» (название компании подставляется клиентом)
  - Description: «Производим приводные, тяговые, транспортные и грузовые цепи по ГОСТ и DIN. Изготовление под заказ по чертежам. Доставка по РФ. Запросите расчёт на сайте.»
  - H1: «Производство промышленных цепей полного цикла»
  - H2/H3: «Каталог продукции», «О заводе», «Клиентам» и т.д.
- **Каталог**:
  - Title: «Каталог промышленных цепей – все виды цепей для промышленности | Название компании»
  - Description: «Полный каталог цепей: приводные, тяговые, транспортные, грузовые, цепи под заказ. Характеристики, фото, цены по запросу.»
  - H1: «Каталог цепей»
- **Страница товара/категории** (если будут динамические): Title/Description формируются по шаблону, H1 — название.
- Уникальные мета-теги для каждой страницы.
- Микроразметка Schema.org не требуется.
- `sitemap.xml` и `robots.txt` — опционально.

## 9. Дизайн-требования
- **Стиль**: современный индустриальный, строгий, технологичный.
- **Цветовая палитра**:
  - `#0d0801` — текст (чёрно-коричневый)
  - `#a5a5a7` — основной фон (бело-алюминиевый)
  - `#4d4d4d` — фон блоков (брезентово-серый)
  - `#fd5226` — акцент (красно-оранжевый) для CTA, иконок, лого
  - `#f1f6f9` — ховеры, контрастный фон (Синяя Элис)
- **Типографика**: крупные заголовки, контрастный текст. Минимальный коэффициент контрастности 4.5:1 для основного текста, 3:1 для крупного.
- **Изображения**: профессиональные фото производства, продукции, команды; видео опционально.
- **Минимализм**: без визуального шума.

## 10. Производительность и доступность
- **Оптимизация изображений**:
  - Формат WebP с fallback на JPEG/PNG.
  - Атрибут `loading="lazy"` для изображений вне первого экрана.
  - Размеры должны соответствовать фактическому отображению.
- **Анимации**: только `transform` и `opacity`, избегать `top/left/margin`. Использовать `will-change: transform` для анимируемых элементов.
- **Адаптивность**:
  - Корректное отображение на десктопе, планшете, мобильном.
  - Мобильное меню (гамбургер), уменьшенные боковые цепи, отключение следящей цепи.
- **Кроссбраузерность**: последние версии Chrome, Firefox, Safari, Edge.
- **Скорость загрузки**: главная страница ≤ 2 сек.
- **Доступность (aria)**: базовые атрибуты для интерактивных элементов, семантическая вёрстка.

## 11. Безопасность
- SSL-сертификат на хостинге.
- Формы защищены от спама (простая honeypot или reCAPTCHA v3).
- Данные пользователей не сохраняются (все отправляется на email), кроме стандартных логов хостинга.

## 12. Политика конфиденциальности
- Отдельная страница `/privacy-policy/` с текстом политики обработки персональных данных.
- Стандартный текст (можно взять шаблон и адаптировать).
- Cookie-баннер не требуется.

## 13. Контентные требования
- Тексты: профессиональная терминология, но доступные для неспециалистов.
- Фото и видео высокого качества.
- SEO-тексты: уникальные мета-теги для каждой страницы.

## 14. Дополнительные замечания для разработчика (Kimi)
- Все тексты, изображения и данные каталога могут быть заполнены заглушками; клиент заменит позже.
- Важно обеспечить работоспособность функционала (слайдер, модальные окна, формы, переключение языка, анимации) с демо-данными.
- Код должен быть хорошо структурирован, комментарии на русском или английском.
- Использовать относительные пути для ресурсов (для статического хостинга).
- Валидация форм на клиенте обязательна, серверная (через внешний сервис) — по возможности.

## 15. Ключевые файлы проекта
- `index.html` — главная страница
- `catalog.html` — страница каталога
- `privacy-policy.html`
- `css/main.css` (или `style.css`) — скомпилированный из SCSS
- `js/main.js` — основной скрипт (навигация, слайдер, модальные окна, формы, переводы, анимации)
- `js/catalog.js` — логика каталога (рендер из JSON)
- `js/translations.js` — объекты с переводами
- `data/catalog.json` — данные каталога
- `assets/` — изображения, иконки, шрифты
